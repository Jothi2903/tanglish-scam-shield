# 🛡️ Tanglish Scam Shield

Detects scam messages written in Tamil, English, and Tanglish (code-mixed),
and explains *why* a message is risky in simple Tamil/Tanglish.

## Problem
Most scam detectors work only for English. In Tamil Nadu, scam messages
(fake KYC, EB bill, OTP requests) often come in Tanglish, and elders and
first-time digital payment users fall for them.

## Features
- Classifies a message as `scam`, `suspicious`, or `safe`
- Works on Tanglish, Tamil script, and English messages
- Explains **why** (link, urgency, OTP request, threats...) in Tanglish or Tamil
- FastAPI backend + Flutter mobile app

## Scam types covered
1. Fake KYC / bank account block
2. OTP / UPI PIN request
3. Lottery / prize / gift
4. Fake job offer / part-time income
5. EB bill / electricity disconnection

## How it works
```
Flutter app -> FastAPI (/predict) -> TF-IDF + Logistic Regression -> label + rule-based explanation
```
- **Model:** character n-gram TF-IDF (handles Tanglish spelling variations) + Logistic Regression
- **Data:** hand-written messages + template-generated Tanglish/Tamil/English messages, including tricky safe messages that contain words like "KYC" or "OTP"
- **Explanation:** rule-based (regex patterns), not generated by the model

## Results
| | v1 (Tanglish only) | v2 (+ Tamil, English, tricky safe) |
|---|---|---|
| Accuracy | 69% | 88% |
| Scam recall | 56% | 89% |

Evaluated on 26 hand-written messages, so treat this as a rough indication.
Training data is partly template-generated, which can make scores optimistic.

## Run it
```bash
pip install pandas scikit-learn joblib fastapi uvicorn
python src/generate_data.py
python src/train_baseline.py
python src/predict.py "Ungal EB bill pending, inniki ratri current cut aagum [LINK]"
uvicorn api:app --reload --app-dir src
```
API docs: `http://127.0.0.1:8000/docs`

Mobile app (Android phone over USB):
```bash
adb reverse tcp:8000 tcp:8000
cd app && flutter run
```

## Limitations
- Small hand-written test set (26 rows)
- Explanations are rule-based and can be wrong if the model is wrong
- Text only (no voice calls, images, or notification reading)

## Ethics
All messages are anonymized or synthetic. Names, phone numbers, and links are
replaced with `[NAME]`, `[PHONE]`, `[LINK]`.
